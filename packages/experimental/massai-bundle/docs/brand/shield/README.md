# The M-shield — the badge

A second, simpler mark the owner liked on sight. It is **not** the product's primary mark: it is
the *badge* — the thing that goes where the plasma sigil would be too arcane.

## What it is

A shield outline, a spear through the top, an **M** filling the field, and an arrow at the foot of
the M's valley pointing down. Flat, one colour, no gradients in the primary file.

## Why it works

- **One colour, one silhouette.** Survives any size, any print process, embroidery, a stamp.
- **The M is negative space inside the shield**, so the whole thing reads as a unit rather than
  a letter with a frame.
- **Spear + shield + arrow** is heraldic, not corporate — it belongs to the same family as the
  crest artwork (lion, warrior, helm) without competing with the sigil's plasma language.

## Where it belongs

| Surface | Mark |
|---|---|
| the site, the tab, the home screen | **plasma sigil** (public face) |
| admin console, docs, engines/workforce pages | **M-shield badge** (official/internal) |
| merch, stamps, patches, one-colour print | **M-shield badge** |
| large hero art, share cards | crest artwork / emissive sigil |
