# Geometry-first marks — the face that is a pattern

The reference set (nine AI renders) all reached for the same thing: a spiky armoured mask with
glowing eyes and a **Flower of Life** disc on the chest. The armour is the cliché. The *flower* is
the only genuinely interesting part — because it is a real object: nineteen circles, exact,
reproducible, and older than any logo.

So these three start from the flower and let the face happen:

| File | Idea | Notes |
|---|---|---|
| `ga.svg` — **Eye of the Flower** | the centre circle is not a circle: it is an eye. Iris gold, pupil a vertical slit. Crown rays outside. | the strongest read; sacred and slightly unsettling, which is right |
| `gb.svg` — the mask | the flower shrunk to a crown above two thin-line eyes and a jaw | weakest of the three: the jaw reads as a beak |
| `gc.svg` — V in the flower | a V drawn across the lattice, glowing | merges the owner's initial with the geometry; the V is dominant, the flower becomes texture |

## Why geometry beats armour as a mark

- Nineteen circles are **mathematically exact** — the mark can be rebuilt from a rule, not traced.
- It is **public-domain archetype**, not a borrowed fantasy style.
- It scales: at 512px you see the lattice; at 16px the centre eye and the outer ring still read.
- And it matches the owner's own belief — that the pattern *is* the world, not decoration on it.

## The one rule these keep

Gold hairlines on near-black, one ember accent. No bevels, no armour plates, no spikes: the
authority comes from the geometry being exact, not from the figure looking dangerous.
