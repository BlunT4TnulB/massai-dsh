# The M mark — crown, eyes, arrow

The owner's reference: a rusted-metal **M** filled with green circuit traces, a crown on top, angry
eyes under it, Matrix katakana in the gaps, lit like a hacker film.

## Verdict on the reference

**What is right:** the *structure*. An M whose centre descends into a **down arrow**, with a crown
above and eyes in the notch. It reads instantly, it has direction (down = into the machine), and it
is the most "engine room" idea anyone has produced for this project.

**What is wrong:** the *palette and the props*. Green neon + circuit traces + rust + katakana is a
borrowed hacker-film language. It dates fast, it says "abandoned machinery" rather than "maintained
tool", and it fights the gold-on-black sacred-geometry brand that the site now runs on. A weathered
rust texture also signals neglect, which is the worst possible signal for software.

`sizes2.png` shows the gold mark at 64 / 32 / 16px — it survives because it is four strokes and two
tick marks, not a render.

## Where it belongs

Not on the door. The public face stays the **plasma Flower of Life**. This is the mark for the rooms
behind it — owner console, local agents, engines, logs — the same job the M-shield badge was doing,
with far more personality.

**Two languages, two rooms:** sacred geometry outside, this machine-mark inside. That split is the
same one already agreed for the face; this simply does it better.
