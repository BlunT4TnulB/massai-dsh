# Skills ships alongside the bundle

Techniques learned while building Massai, written so a future session (or a future human) does not
rediscover them the hard way. The same files live in `~/.dsh/skills/` so the agent can load them as skills.

- [`infinite-zoom-canvas`](infinite-zoom-canvas/SKILL.md) — logarithmic octave renormalisation,
  multi-octave alpha envelopes, the canvas DPR transform, visual-viewport measurement, and how to
  photograph a canvas with headless Chromium. Reference notes on the screensaver that inspired it:
  [`reference/gemini-screensaver.md`](infinite-zoom-canvas/reference/gemini-screensaver.md).
